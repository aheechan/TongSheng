**升级包：** `TongSheng-1.1.11-beta-TextRec_mode-update.zip` — 0.49 MB，仅含代码

**SHA256：** `1096cd909501110000ff7241b241e53e4a54fc033a50f889b87bf982a4b0ae69`

## 这个测试版增加了什么

第二个工作模式：不打字说话，而是输入文字——程序把它翻译出来，用你的克隆音色朗读，并保存为 WAV 文件。

### 模式切换

- 主窗口右上角、**声音模型训练**按钮右侧只有一个按钮，按钮上显示当前模式，点击即在**语音输入模式**与**文字录音模式**之间切换。
- 按钮下方有一行小字提示：**模式切换**。
- 语音输入模式保持原有的蓝调暗色主题；文字录音模式整体转为微翠绿的暗色，不看文字也能感知当前模式，两者都仍是暗色调。
- 模式会记录在 `config.yaml` 中，下次启动自动恢复。

### 文字录音模式下

- 「保存合成音频（录音）」这一行替换为**三行高、可滚动的文字输入框**，样式与下方文字呈现区一致。`Ctrl+Enter` 提交，`Enter` 换行。
- **输入语种自动识别**：假名判定为日文，谚文判定为韩文，汉字判定为中文，其余判定为英文。随包的语音前端支持中文、英文、日文、韩文与粤语。
- 主操作按钮变为文字录音，结果写入
  `results\rec-text\YYYYmmdd-HHMMSS-48k.wav`（48 kHz PCM），并用克隆音色播放。
- 语言开关的标签从「输入语言」改为**「界面语言」**：只在中英文界面之间切换，不再重新加载识别引擎。
- **进入该模式即释放识别引擎**（关闭引擎并清空 CUDA 缓存），切回语音输入时**自动重新加载并预热**。
- 麦克风电平表与「模型预热」按钮会隐藏，因为此时不涉及录音采集。

## 本测试版修复

- **显式选择的输出语言现在会被尊重。** 此前当输出语言选为中文、输入也是中文时，程序会强制翻成英文并用英文朗读。现在显式选择始终优先，只有输出语言留空时才自动取反。
- **升级前的进程检查范围收窄。** 以前只要机器上存在任意 `pythonw.exe` 进程，覆盖就会中止；现在只检查目标安装目录下的同声进程。

## 安装方法

1. 从托盘退出同声。
2. 把 `TongSheng-1.1.11-beta-TextRec_mode-update.zip` 解压到安装目录下的子文件夹，例如
   `D:\TongSheng\TongSheng-1.1.11-beta-TextRec_mode\`。
3. 双击该文件夹内的 `apply_update.bat`，看到屏幕上打印的版本号 1.1.11 即为成功。
4. 启动同声，运行开始菜单中的 **自检**，十项检查需全部通过。

覆盖包只替换程序代码、工具与文档。模型、`config.yaml`、录音文件与已训练音色（`voice-repository`）都不会被覆盖或删除。

## 已知限制

- 文字录音模式不进行语音识别，识别模型是被有意卸载的。
- 翻译仍依赖随包的本地 llama.cpp 服务，程序会按需自动拉起。
- 语种判断基于字符区间，中英混排等文本可能被归入其主要字符所属的语种。
- 本测试版只提供覆盖包，不能用于全新安装；请先安装 1.1.11 完整版。
