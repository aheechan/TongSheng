# TS / 实时语音翻译 · Logo 概念提案

4 个 512 × 512 的 SVG 图标方案。共同视觉基因：深海军黑底、青色到电光蓝的冷色渐变、圆角方形图标、极细网格、几何化麦克风与人耳，以及 T / S 双字母。

> TS 可理解为 **同声（Tóng Shēng）**，也可理解为 **Translate + Speak**。四个方向都把「说」与「听」压缩进同一枚符号。

---

## 01 同声连字 / LIGATURE

**概念：** 白色 T 同时是麦克风，蓝色 S 的曲线同时是耳廓。字母与器件共用一条笔画，形成横向连字。

- **T：** 顶部网罩 + 竖向手柄 + 蓝色 U 形悬挂架 + 底座
- **S：** 一条连续的耳形曲线，内嵌浅色耳蜗弧线
- **气质：** 字标感最强，像一枚声音品牌的主字母组合
- **适合：** 启动页、官网首屏、品牌字标延展

**文件：** `01-ligature.svg` / `01-ligature.png`

---

## 02 声场徽章 / SEAL

**概念：** 蓝色渐变圆形声场，TS 以负形直接刻入徽章。T 带网罩与麦克风底座，S 的内侧弧线暗示耳蜗。

- **T：** 负形麦克风，青色网罩线 + 细支架 + 底座
- **S：** 负形字母，内部藏一条耳蜗弧线与一个光点
- **气质：** 对比最强，缩到 32–64 px 仍能读出 TS
- **适合：** App Icon、社交头像、通知角标

**文件：** `02-seal.svg` / `02-seal.png`

---

## 03 声流 / SIGNAL

**概念：** 麦克风发出 S 形声流，斜向穿过声场，最终汇入右侧人耳。强调「实时」与「同声传译」的流动感。

- **T：** 左下角白色麦克风，独立成字
- **S：** 居中的蓝色声流，从麦克风指向人耳
- **耳：** 右侧完整耳廓，内部有浅青耳蜗线
- **气质：** 最有叙事性和动势，适合做品牌辅助图形
- **适合：** 产品介绍页、动效 LOGO、品牌图形系统

**文件：** `03-flow.svg` / `03-flow.png`

---

## 04 聆听之环 / LISTEN（推荐主标）

**概念：** 完整的人耳轮廓包裹 TS 字标：T 是麦克风，S 是声波。以「聆听」承接翻译，概念最完整。

- **耳：** 一条连续的蓝色耳廓，构成图标的视觉外环
- **T：** 白色麦克风字标，带网罩与底座
- **S：** 蓝色声波，贴在耳廓内侧
- **气质：** 最像一枚成熟的品牌符号，兼顾人耳识别与 TS 识别
- **适合：** 主标、App Icon、硬件产品丝印

**文件：** `04-listen.svg` / `04-listen.png`

---

## 推荐组合

- **主标：04 聆听之环** — 人耳轮廓最有记忆点，T / S / 麦克风 / 人耳四要素完整。
- **字标延展：01 同声连字** — 横向比例更适合做导航栏、文档页眉和社交媒体横幅。
- **图标系统：02 声场徽章** — 负形对比度最高，最适合小尺寸和 App Icon。
- **品牌图形：03 声流** — 适合做加载动画、声波延展和发布会主视觉。
